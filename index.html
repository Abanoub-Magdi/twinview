Share your screen

You’ll get a room code. Send it to the other person. For full mouse/keyboard control on Windows, also run the local control agent once.

Enable remote control (Windows agent)

Screen viewing works in the browser alone. To let the visitor move your mouse and type, run this in PowerShell from the host-agent folder: 

powershell -ExecutionPolicy Bypass -File .\Start-ControlAgent.ps1

Leave that window open while you host. Status shows below after you start sharing.
